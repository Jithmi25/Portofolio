# Jithmi's Portfolio

A React portfolio website showcasing projects, services, technical sessions, latest content, and contact information.

## Features

- Home, About, Portfolio, Services & Events, and Contact sections
- Services loaded from Supabase with configurable Lucide icons
- Upcoming and past sessions loaded from Supabase
- Latest YouTube and Medium content links
- Session actions based on event status:
  - Completed sessions with a YouTube link show **Watch Recording**
  - Upcoming sessions with a registration link show **Register Now**
  - Upcoming sessions without registration show **Coming Soon**
  - Sessions without a fixed date show **Date: Coming Soon**
- AOS animations and responsive Tailwind CSS layouts

## Tech Stack

- React 18 and Vite
- Supabase
- Tailwind CSS
- Lucide React icons
- AOS animations
- React Router

## Supabase Configuration

Create a `.env` file in the project root. Do not commit this file or expose the service-role key in the frontend.

```env
VITE_SUPABASE_URL="https://your-project.supabase.co"
VITE_SUPABASE_ANON_KEY="your-anon-key"
```

The app reads these tables:

- `services`: service cards shown in **Services I Offer**
- `content_links`: YouTube, Medium, and other content cards
- `events`: upcoming and completed sessions shown in **Upcoming & Past Sessions**

### Events Table

Run the following SQL in the Supabase SQL Editor:

```sql
create table if not exists public.events (
	id bigint generated by default as identity primary key,
	title text not null,
	description text not null,
	event_date text not null default 'Coming Soon',
	status text not null default 'coming_soon'
		check (status in ('upcoming', 'completed', 'coming_soon')),
	registration_link text,
	youtube_link text,
	thumbnail text,
	platform text not null default 'Online'
);

alter table public.events enable row level security;

create policy "Public can read events"
	on public.events for select
	using (true);
```

Column reference:

| Column              | Type     | Notes                                        |
| ------------------- | -------- | -------------------------------------------- |
| `id`                | `bigint` | Primary key                                  |
| `title`             | `text`   | Session title                                |
| `description`       | `text`   | One or two sentence description              |
| `event_date`        | `text`   | For example, `2026-10-15` or `Coming Soon`   |
| `status`            | `text`   | `upcoming`, `completed`, or `coming_soon`    |
| `registration_link` | `text`   | Nullable registration URL                    |
| `youtube_link`      | `text`   | Nullable recording URL                       |
| `thumbnail`         | `text`   | Nullable image URL                           |
| `platform`          | `text`   | For example, Zoom, YouTube Live, or Physical |

### Service Icons

Add an `icon` column to the existing `services` table:

```sql
alter table public.services
	add column if not exists icon text default 'Code';
```

The value should be a supported icon name or a service title. Supported icon names include:

`Code`, `Palette`, `Server`, `Smartphone`, `Database`, `Cloud`, `Briefcase`, and `Figma`.

Example service updates:

```sql
update public.services
set icon = 'Briefcase'
where title = 'Project Management';

update public.services
set icon = 'Figma'
where title = 'UI/UX Design';

update public.services
set icon = 'Code'
where title = 'Full Stack Development';
```
